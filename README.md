# megaFlightAI

Учебный агент на LangGraph помогает в чате узнавать статус авиарейсов и оформлять демонстрационные бронирования. Он определяет намерение пользователя, уточняет недостающие данные, обращается к инструменту статуса или бронирования и отвечает на основе его результата. Контекст разговора позволяет продолжить работу с ранее выбранным рейсом. Используется модель `deepseek/deepseek-v4-flash` через OpenAI-compatible API (`https://sprutdock.ru/v1`).

Рейсы и бронирования демонстрационные: данные тестовые, реальный билет не оформляется. Используйте только вымышленные данные пассажиров и паспортов. Не публикуйте API-ключ и не передавайте настоящие паспортные данные; полный номер паспорта не должен попадать в ответы и логи.

## Запуск

Нужны Docker и Docker Compose. Скопируйте пример настроек, укажите ключ в созданном файле `.env` и запустите интерактивный чат:

```sh
cp .env.example .env
docker compose run --rm app
```

При первом запуске Compose соберёт образ. Для пересборки после изменений используйте `docker compose build`.

## Проверка

Тесты запускаются отдельным сервисом без передачи ключа. Команда использует `pytest -v -s`, чтобы показать подробности и метрики:

```sh
docker compose run --rm tests
```

Если `LLM_API_KEY` не задан, Compose может вывести предупреждение о переменной сервиса `app`; тестовому сервису ключ не передаётся. По спецификации тесты должны охватывать, в частности, выбор инструментов и безопасность.

## Остановка и очистка

Завершите интерактивный сеанс через Ctrl+C или выход из чата. Контейнер, запущенный с `--rm`, удаляется автоматически. Для очистки ресурсов Compose и собранных образов:

```sh
docker compose down --rmi local --remove-orphans
```
